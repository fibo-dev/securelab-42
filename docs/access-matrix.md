# Матриця доступу до ресурсів (Incident)

| Дія | Анонім | Reporter (власник) | Reporter (чужий) | Analyst | Administrator | Реалізація / тест |
|---|---|---|---|---|---|---|
| Details | 401 | 200 | 404 | 200 (з internal) | 404 (прав немає) | `VisibleTo`, A-02/A-03/A-03R |
| List | 401 | лише власні | лише власні | усі | лише власні (порожньо) | `VisibleTo`, A-05 |
| Create | 401 | 201, owner з principal | - | 201 | 201 | ЛР 3 |
| Update content | 401 | 204 | 404 | 404 | 404 | A-04, A-08a |
| Delete | 401 | 204 | 404 | 404 | 404 | A-04 |
| Triage | 401 | 403 | 403 | 204 лише для `New`, інакше 409 | 403 | A-06, A-07, A-09 |
| Child comment | 401 | 200 (не internal, свій incident) | 404 | 200 (усі) | 404 | A-12 |

## Політика відмови
Чужий і неіснуючий ресурс дають однаковий статус **404**, щоб не розкривати факт існування ресурсу. 
Для операції Triage повертається **403**, оскільки рішення про роль ухвалюється до пошуку конкретного ресурсу.
